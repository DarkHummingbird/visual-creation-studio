## 接口基线

用户从模型页面提供的图片端点：

```text
POST https://cn-beijing.maas.qianwenaiapi.com/api/v1/services/aigc/multimodal-generation/generation
Authorization: Bearer <从本地环境读取>
Content-Type: application/json
```

最小图片请求体可保持简单商品图，避免引入人物、文字审核及复杂提示词干扰：

```json
{
  "model": "qwen-image-3.0",
  "input": {
    "messages": [{
      "role": "user",
      "content": [{"text": "一只白色陶瓷杯放在木桌上，自然光，写实商品摄影，无人物，无文字。"}]
    }]
  },
  "parameters": {
    "size": "1024*1024",
    "n": 1,
    "prompt_extend": true
  }
}
```

模型ID固定为标准版 `qwen-image-3.0`，不要替换为Pro。旧请求还传过 `watermark:false`；新测试优先按官方最小参数，参数合法性先核对，不通过反复付费试错确定。

视频基线：

```text
POST https://cn-beijing.maas.qianwenaiapi.com/api/v1/services/aigc/video-generation/video-synthesis
X-DashScope-Async: enable
GET https://cn-beijing.maas.qianwenaiapi.com/api/v1/tasks/{task_id}
Authorization: Bearer <从本地环境读取>
```

```json
{
  "model": "wan3.0-video-prime",
  "input": {
    "prompt": "镜头缓慢靠近桌上的陶瓷杯，保持杯子外观不变。室内环境声，无对白，无背景音乐。",
    "media": [{"type": "first_frame", "url": "<本次生成图片的有效URL>"}]
  },
  "parameters": {
    "resolution": "480P",
    "ratio": "adaptive",
    "duration": 5,
    "audio": true
  }
}
```

视频端点以模型页面或当前官方文档为准。统一记录最终实际使用的域名；不要在出错时自动在多个域名重复提交。首帧模式不混传 `reference_image` 等互斥类型。提交前确认图片URL仍有效；需要重新生图时须计入预算。

官方技术资料：
- 图片：https://platform.qianwenai.com/docs/developer-guides/image-generation/text-to-image
- 视频：https://platform.qianwenai.com/docs/developer-guides/video-generation/wan30-video

## 建议执行顺序

1. 读取本交接和已有证据，只检查密钥是否配置，不输出值。检查是否已有测试输出或后台任务，避免重复创建。
2. 先排查DNS、HTTPS、代理和运行环境。代理配置只记录是否存在及是否生效，不输出带账号密码的URL。不要关闭证书校验，不擅自修改用户系统网络设置。
3. 对比Python与其他HTTP客户端的连接表现；确认网络允许访问后，再考虑提交一次真实请求。根路径404和模型列表请求都不能替代真实生成测试。
4. 如有可访问的平台调用记录，先核对旧请求，记录结果；如无平台访问权限，明确保留“不明”，按潜在收费计入上限，不要求用户重新给Key。
5. 新脚本在发送POST前落盘请求快照、时间和保守费用；不保存鉴权头。响应到达后立刻保存脱敏原始响应、request_id、task_id。响应丢失时标记不明，禁止自动POST重试。
6. 图像下载后检查可解码、格式及尺寸。成功后才继续一次视频提交；立即保存task_id，然后轮询同一任务。轮询暂时失败可有界重试，但不新建视频。
7. 视频完成后下载本地，使用ffprobe等工具确认视频流、约5秒时长、480P档位对应的实际宽高和音轨。没有ffprobe先检查本地可用工具，不为本任务重建Demo或修改全局环境。
8. 每次等待尽量不超过60秒，阶段变化或遇到阻塞时告知用户。一次运行未完成时保存检查点，下次继续查询同一任务。
9. 报告完成后停止，不继续Demo开发或扩大评测。
